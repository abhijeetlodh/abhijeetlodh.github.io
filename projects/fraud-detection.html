Credit Card Fraud Detection (AWS MLOps)

Business Problem

Detect fraudulent transactions in highly imbalanced financial dataset.

Pipeline

Data Ingestion
AWS S3 → Raw transaction data ingestion
EDA + Preprocessing
IQR outlier removal, scaling, feature selection
Model Training
Logistic Regression → Decision Tree → Random Forest
Evaluation
F1-score optimization due to imbalance
Deployment
Docker → EKS → EC2 → API endpoint

Tech Stack

AWS Sagemaker
Model training + experiment tracking
MLflow
Tracking metrics, model registry
CloudWatch
Monitoring latency + drift
SNS
Alerting system via email

Metrics

  • F1 Score improved from 0.72 → 0.91
  • Handled imbalanced data via SMOTE
  • Real-time detection latency < 500ms

Challenges

  • Severe class imbalance
  • Data drift → retraining pipeline
  • False positives vs business cost

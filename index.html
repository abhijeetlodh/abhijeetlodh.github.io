🚀 GitHub Pages Setup Guide

Step 1: Create GitHub Account

Go to github.com and sign up for free

Step 2: Create New Repository

• Click the + icon (top right) → "New repository"

• Name it: yourusername.github.io

• Make it Public

• Check "Add a README file"

• Click "Create repository"

Step 3: Upload Files

• Click "Add file" → "Upload files"

• Drag your index.html file

• Click "Commit changes"

Step 4: Create Images Folder

• Click "Add file" → "Create new file"

• Type: images/placeholder.txt

• This creates the folder! Add any text and commit

• Now upload your certificate images to this folder

Step 5: Update Image Paths

• Edit index.html on GitHub

• Change image src to: images/your-cert-name.jpg

✨ Your site will be live at:

https://yourusername.github.io
